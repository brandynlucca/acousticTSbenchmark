# acousticTSbenchmark

Comparative timing benchmarks for acoustic backscattering by prolate spheroids.

Times acousticTS, Prol_Spheroid (vectorized), echoSMs, and liquid_spheroid. AcousticScattering.jl supplies cached BEM/FEM-BEM references for ΔTS comparisons.

In **Actions → Dense spheroid timings → Run workflow**, choose `new` and set the frequency range/interval (kHz), semimajor axis `a` (m), aspect ratios, incidences, boundaries, software, and platform. Defaults cover all four boundaries at 0°, 37°, and 90° with acousticTS and Prol_Spheroid from 1 to 300 kHz. Unsupported combinations are recorded as skips. **Complete each frequency sweep** finishes the full spectrum for one size, aspect ratio, incidence, and boundary combination before moving on, comparing the selected software sequentially at each frequency. Choose **Frequency by frequency** to visit all combinations before advancing frequency.

Choose `resume` and enter the previous run ID to continue its saved cases with its original settings, including platforms that were queued when the run stopped. **Resume order** can complete each frequency sweep while keeping all saved measurements, or retain the saved order. The default budget is 240 minutes per platform, including setup, with 45 and 120 minutes also available. Large grids require multiple sessions. References run separately and are cached. Results are downloadable artifacts.

Choose `extend`, enter the previous run ID, and set **Selected software** to continue only that software's missing cases, preserving compatible saved measurements and all other comparison curves. Use `refresh` instead to restart the selected software at the currently pinned version. Both restore the saved geometry, controls, and platforms. **Frequency grid for extend or refresh** defaults to **Keep saved frequency grid**. Select **Use frequency inputs above** to change only the selected software's frequency grid. For liquid_spheroid at 2, 4, ..., 100 kHz, choose `extend`, set **Selected software** to `liquid_spheroid`, enter the previous combined run ID, and set start/end/interval to `2`/`100`/`2`. Other software retains its full saved curves. Later, extend the resulting run with end frequency `200` or `300` to reuse completed liquid_spheroid cases and calculate the missing ones. An extension must include every already-recorded selected-software case. Saved benchmark series dispatch one campaign at a time after its predecessor finishes.

[Live progress](https://brandynlucca.github.io/acousticTSbenchmark/) shows time and ΔTS together, a cost–error view, and sampled peak additional RAM per prediction in MiB. Colored X markers show failed predictions at their recorded time to failure. Select `a` (0.001, 0.01, 0.07, 0.1, or 0.5 m) to view its latest saved campaign on the chosen platform. Sizes without results stay empty. Size, aspect ratio, and incidence selections apply to every plot and the coverage table.

[Download all results](results/) as SQLite or compressed CSV. The dataset updates from saved artifacts and keeps earlier software versions. Duplicate copies from resumed runs are removed.
