# acousticTSbenchmark

Comparative timing benchmarks for acoustic backscattering by prolate spheroids.

Times acousticTS, Prol_Spheroid (vectorized), echoSMs, and liquid_spheroid. AcousticScattering.jl supplies cached BEM/FEM-BEM references for ΔTS comparisons.

Run benchmarks manually through GitHub Actions. References run in parallel on separate runners and are reused across platforms. Results are saved as downloadable artifacts.

[Live progress](https://brandynlucca.github.io/acousticTSbenchmark/)
