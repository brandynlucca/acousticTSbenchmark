# acousticTSbenchmark

Comparative timing benchmarks for acoustic backscattering by prolate spheroids.

Includes acousticTS, Prol_Spheroid (vectorized), echoSMs, liquid_spheroid, and AcousticScattering.jl (BEM/FEM-BEM).

Run benchmarks manually through GitHub Actions. Results are saved as downloadable artifacts.

[Live progress](https://brandynlucca.github.io/acousticTSbenchmark/)
